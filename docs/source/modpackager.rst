CollabXR Mod Packager
===========================

In order to load your own objects into CollabXR, you must package them as a "mod."
The ``com.ecmodding.modpackager`` Unity package is used to bundle and upload mods to a mod repository for use within CollabXR.

It is recommended you review Unity's `Asset Bundles`_ system in order understand to limitations and platform compatibility before using the Mod Packager.

.. _Asset Bundles: https://docs.unity3d.com/6000.0/Documentation/Manual/AssetBundlesIntro.html
