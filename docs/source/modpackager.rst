CollabXR Mod Packager
===========================

In order to load custom objects into CollabXR, you must package them as a "mod."

The `CollabXR Mod Packager`_ Unity package is used to bundle and upload mods to a mod repository for use within CollabXR.
Install instructions are included on the repository page.

Mods must be uploaded to a :doc:`Mod Repository <modpackager/modrepository>` in order to be loaded into CollabXR.

.. _CollabXR Mod Packager: https://github.com/Envision-Center/CollabXR-Mod-Packager
