CollabXR Mod Extras
=====================

The `CollabXR Mod Extras`_ Unity package is used to include CollabXR-specific functionality in your projects, such as toggle controllers, object cyclers, and other utilites.
Install instructions are included on the repository page.

Most MonoBehaviors in this package should have tooltips to assist in understanding and working with components, but you can always refer to this documentation for more detailed explanations of what a component does.

.. _CollabXR Mod Extras: https://github.com/Envision-Center/CollabXR-Mod-Extras
